# Multitool Stage 6 — HAT + Saddle Mechanical Baseline

This release consolidates the preferred mechanical architecture:

- stock Multicomp Pro / Lincoln Binns Pi-Box Pro 5 retained as lower Pi/cooling module;
- Multitool remains a standard HAT-compliant board;
- HAT remotely mounted on a rigid U-shaped aluminium saddle;
- short 40-way ribbon provides electrical connection only;
- saddle carries IEEE-488 and service connectors;
- stock Pi Active Cooler remains unobstructed;
- two-box and large generic-instrument-case solutions become fallbacks.
