# Main HAT Hardware

This directory will contain the Multitool main HAT schematic, PCB and fabrication outputs.

Initial functions:

- Raspberry Pi 5 40-pin interface.
- GPIB transceivers.
- GPIB termination/protection.
- HAT ID EEPROM and disable jumper.
- Service/programming header.
- Test points.
- Internal interconnect to chassis-mounted IEEE-488 connector.

Schematic capture is intentionally deferred until the GPIO and voltage-compatibility review is complete.
