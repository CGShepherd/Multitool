# Multitool Stage 7 — Saddle Interface Definition

This release freezes the three critical mechanical interfaces:

1. saddle -> Pi-Box: four existing upper front/rear enclosure fastener positions;
2. HAT -> saddle: four removable M2.5 standoffs on the standard HAT pattern;
3. IEEE-488 connector -> saddle: panel-mounted directly into the rear vertical saddle face.

Important correction: published Pi-Box documentation describes Plastite/Taptite fasteners,
not simply ordinary machine screws. The exact longer replacement fastener must be selected only after
the actual screw type and available engagement depth are confirmed.
