# Multitool Stage 8 — Modular Saddle + IEEE-488 Bracket

This release refines the upper mechanical architecture into two simple home-fabricated parts:

1. main U-shaped saddle;
2. removable IEEE-488 connector bracket.

The main saddle is deliberately reduced to two 90-degree bends so it can be fabricated with a small
benchtop brake from 2.0 mm aluminium.

The connector bracket is preferably flat, making the IEEE-488 aperture easy to machine separately.
It bolts to the saddle with four M3 fasteners and can be remade independently if connector/service
requirements change.

This architecture is now preferred for Rev A.
