# Serial EEPROM Adapter

Planned first-use cases:

- 24Cxx I2C EEPROMs.
- Tektronix programmable-feature-module EEPROMs, once exact part numbers are confirmed.

The adapter should support:

- device power selection where required;
- SDA/SCL access;
- write-protect control where applicable;
- safe connection/disconnection;
- read, write and verify workflows.
