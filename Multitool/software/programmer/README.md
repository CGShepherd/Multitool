# Programmer Software

Planned capabilities:

- HAT EEPROM read/program/verify.
- 24Cxx EEPROM read/program/verify.
- DS1742 raw dump.
- DS1744P image construction/program/verify.
- Mandatory binary backup before writes.
- Byte-for-byte verify after programming.
- Human-readable metadata and timestamped archive files.
- RTC/control-region decoding for DS17xx devices.

No image-density translation shall be performed implicitly.
